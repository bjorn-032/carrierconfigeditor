# Carrier Config Editor
Carrier Config Editor is a very simple app to change parts of the carrier config on unrooted Android devices.
For example you can import a config to show the roaming indicator only in countries outside of the EU, for this take a look at the roamingConfigs folder, which contains a few examples.

This project is based on another similar project, [CarrierVanityName](https://github.com/nullbytepl/CarrierVanityName), that allows you to change the carrier name. 

The app uses [Shizuku](https://shizuku.rikka.app/) to achieve this using carrier config overrides. This method was inspired by Kyujin Cho's [pixel-volte-patch](https://github.com/kyujin-cho/pixel-volte-patch), which uses the same method to enable VoLTE on some Google Pixel and LG devices.
